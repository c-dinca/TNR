# ADR-0000: Template

- **Status**: Proposed | Accepted | Superseded by ADR-XXXX | Withdrawn
- **Date**: YYYY-MM-DD
- **Deciders**: who
- **Affects**: which docs, contracts, packages

## Context

What forces this decision? Constraints, requirements (cite `FR-###`/`NFR-###`), and what happens if we choose
badly. Be specific about the situation, not about the answer.

## Options considered

### Option A — name

How it works, briefly.

**For:** …
**Against:** …

### Option B — name

**For:** …
**Against:** …

State each option as its strongest self. An ADR that rejects a straw man is worthless six months later when
someone re-litigates the decision.

## Decision

What we chose, stated plainly.

## Consequences

**Positive** — what this buys us.

**Negative** — what it costs us. **Mandatory.** If there is no cost, this was not a decision.

**Neutral** — what changes without being better or worse.

## Revisit when

The concrete signal that should make us reopen this: a measurement, a scale threshold, a customer requirement.
